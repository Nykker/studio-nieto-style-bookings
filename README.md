# Studio Nieto Style Bookings

Build a simple booking app for a small hair salon. Users can sign up and log in with email. Logged-in users can pick a service (haircut, color, beard), a date and a time, and book an appointment. They see a list of their own bookings and can cancel one. Use a database to store bookings. Clean, modern design.
